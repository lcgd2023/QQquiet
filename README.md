# 企鹅别叫--by lcgd2023

一款用于修改QQ接收消息提示音的小工具。

## 功能

- **安静** - 将QQ提示音替换为无声
- **飞机音** - 将QQ提示音替换为飞机音效
- **战斗机音** - 将QQ提示音替换为战斗机音效
- **返回原本音频** - 恢复QQ默认提示音
- **自定义** - 选择任意wav文件替换为QQ提示音
- **开机自动运行** - 开机自动隐藏到系统托盘

## 使用方法

1. 双击运行 `penguin_qq_sound.exe`
2. 弹窗中点击 **继续** 或 **开始** 进入主界面
3. 选择需要的音效按钮即可替换
4. 勾选 **开机自动运行** 后，下次开机自动隐藏到托盘

## 托盘模式

- 设置自启动后，程序开机自动隐藏到系统托盘
- 右键托盘图标：**打开设置** / **退出**
- 托盘模式下再次双击exe，会自动弹出主窗口

## QQ适配

通过运行中的QQ进程自动定位安装目录，支持不同版本号，无需手动配置。

要求：使用前请先打开QQ。
