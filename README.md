# 企鹅别叫--by lcgd2023

一款用于修改QQ接收消息提示音的小工具。

## 功能介绍

| 按钮 | 功能 |
|------|------|
| **安静** | 将QQ提示音替换为无声 |
| **飞机音** | 将QQ提示音替换为飞机音效 |
| **战斗机音** | 将QQ提示音替换为战斗机音效 |
| **返回原本音频** | 恢复QQ默认提示音 |
| **开机自动运行** | 勾选后开机自动在后台运行 |
| **保存设置** | 保存自启动配置 |

## QQ路径适配

自动扫描所有盘符，查找以下路径格式：

```
<盘符>:\QQ\versions\<版本号>\resources\app\resource\msg.wav
```

示例：`D:\QQ\versions\9.9.18-32869\resources\app\resource\msg.wav`

无论QQ安装在哪个盘、版本号是多少，均可自动适配。

## 使用方法

1. 双击运行 `penguin_qq_sound.exe`
2. 在弹窗中点击 **继续** 或 **开始** 进入主界面
3. 选择需要的音效按钮即可替换
4. 勾选 **开机自动运行** 后点击 **保存设置**
